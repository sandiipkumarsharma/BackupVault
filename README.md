# Backup Vault

Private, ad-free backup & restore for Android — contacts, SMS, call logs, calendar and apps.
No internet permission: your data stays on your phone (share a backup to Drive only if you choose).

- **Contacts**: full VCF backup, duplicate finder (same number / same name / similar name), merge or delete,
  VCF → Excel review sheet, corrected Excel → clean VCF
- **Messages**: XML backup; restore (temporarily as default SMS app, then switch back)
- **Call logs** (JSON) and **Calendar** (.ics) backup & restore, duplicates skipped
- **Apps**: save installed apps as .apk / .apks and reinstall
- **Auto-backup**: daily/weekly, keeps the last N backups

Build: GitHub Actions → *Build APK* → artifact **BackupVault-apk**.
